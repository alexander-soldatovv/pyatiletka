# 01. Мастер-промт для Claude Code (вставить первым сообщением)

Как использовать: распакуйте архив в пустую папку будущего репозитория, откройте в ней Claude Code (лучше самую сильную модель и режим с высоким уровнем рассуждения), вставьте блок ниже целиком. Дальше идите по файлу `02_PROMPTS_STAGES.md` по порядку (P0, P1, ...).

Структура папки после распаковки:

```
TZ.md                      главное ТЗ v2 «Пятилетка» (читать целиком)
01_MASTER_PROMPT.md        этот файл
02_PROMPTS_STAGES.md       промты по этапам P0-P10 + репетиция защиты
03_ОПРОС_И_ИНТЕРВЬЮ.md     опрос, скрипт интервью, шаблон анализа
README_FIRST.md            инструкция для капитана
starter/                   данные v2, pension-age.js с тестами, универсальные модули
alt_novosel/               запасная концепция «Новосёл» (не трогать без команды)
docs/case.pdf              текст кейса
```

## Заметки капитану

- Если у Claude Code есть доступ к интернету (WebFetch/WebSearch), он сам проверит dev.max.ru. Если нет, откройте страницы из TZ.md раздела 18 и дайте ему текст.
- Токен бота не вставляйте в чат с Claude Code. Кладите в файл `.env` (он в `.gitignore`), Claude Code читает его через переменные окружения.
- Если Claude Code предлагает «упростить» ТЗ и убрать метки происхождения, тесты, `/reset` или региональные пакеты, отказывайтесь: это ровно то, за что дают баллы.
