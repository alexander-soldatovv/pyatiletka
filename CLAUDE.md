# CLAUDE.md: проект «Пятилетка»

## Что это

Бот и мини-приложение в MAX: личная карта прав и шагов для человека за 5 лет до пенсии. Даты ориентировочные. Источник истины: `TZ.md`. Кейс: `docs/case.pdf`.

## Команды

- Установка: `npm ci`
- Тесты: `npm test`
- Запуск локально: `npm start`
- Docker: `docker compose up --build`
- Проверка данных: `npm run check:data`
- Сканер секретов: `npm run check:secrets`

## Архитектура

Один процесс Node.js: бот, HTTP-сервер, планировщик напоминаний. Хранилище: `node:sqlite`. Юридические правила находятся в `data/*.json`. Расчёт: `src/pension-age.js`.

## Жёсткие правила

1. Не выдумывать факты. Непроверенное явно помечать.
2. Юридические утверждения хранить в `data/*.json`, со ссылкой, датой проверки и меткой происхождения.
3. Секреты брать только из окружения. Не писать их в код, логи, документацию, тесты или git.
4. Не хранить СНИЛС, телефон, паспорт, ФИО, фото и полную дату рождения.
5. Не давать медицинские советы, не ставить диагнозы, не считать размер пенсии.
6. Любые даты права и статус показывать как ориентировочные, со ссылкой на подтверждение в СФР.
7. Не имитировать интеграции с Госуслугами, СФР, МВД или ЕГИСЗ.
8. Не использовать U+2014 в коде, тестах и пользовательских строках.
9. Интерфейс и документация на русском языке, обращение на «вы», короткие фразы.
10. Не добавлять нативные npm-модули. Версии зависимостей фиксировать.
11. После каждого этапа запускать тесты. Ограничения писать в `docs/known-limitations.md`, блокеры в `docs/blockers.md`.

## MAX API

- Базовый адрес: `https://platform-api2.max.ru`.
- Токен передаётся только в заголовке `Authorization`.
- Для соединения требуется сертификат Минцифры.
- Лимит: 2 сообщения в секунду на диалог, текст до 4000 символов.
- Мини-приложение работает по HTTPS, `initData` проверяется на сервере.
- Polling предназначен для разработки, в production нужен webhook.

## Стиль кода

ESM, Node.js 22+, небольшие модули, чистые функции, внедрение зависимостей для тестов, структурные логи без персональных данных.

## Не входит в MVP

Досрочные пенсии, размер пенсии, хранение документов, неподтверждённые интеграции и публичный API.
