# Допущения A1-A10

Обновлено: 30.09.2026. Статус `частично` означает, что контракт, mock или хост проверен, но реальный клиент MAX ещё не подтверждён человеком.

| Код | Допущение | Статус | Уже есть | Что закроет пункт |
|---|---|---|---|---|
| A1 | ID из подписанного `initData` совпадает с ID в обновлениях бота | не проверено | `/id` и серверная P6-диагностика реализованы | Сравнить два значения в реальном Mini App |
| A2 | `web_app` в `open_app` принимает username бота | частично | SDK 0.3.1 формирует ожидаемый payload, mock принимает | Открыть P6-карточку в реальном MAX |
| A3 | Известно поведение `open_app` без заданного Mini App URL | не проверено | Link-fallback срабатывает при отказе API | Записать поведение до и после настройки URL |
| A4 | Docker соединяется с MAX API с сертификатом Минцифры | частично | Bundle и TLS с хоста проверены, HTTP 401 без токена | `npm run smoke:real -- --container` при запущенном Compose |
| A5 | `clipboard` работает на iOS, Android и web | частично | Payload SDK и браузерный fallback покрыты тестами | Вставить строку после нажатия на трёх платформах |
| A6 | Webhook с секретом принимает реальные события | частично | Точное имя заголовка и отклонение неверного секрета покрыты integration test | Публичный webhook + реальная команда `/id` |
| A7 | Для выданного организаторами бота можно задать URL Mini App | не проверено | Официальная инструкция настройки подтверждена | Ответ организаторов или доступное поле настроек |
| A8 | Бот может писать первым после `bot_started` | частично | Очередь и напоминания работают на mock | Получить карточку через `--send` без нового входящего сообщения |
| A9 | Старое callback-сообщение редактируется через `/answers` | частично | `/answers` и fallback на новое сообщение покрыты mock | Нажать кнопку в сообщении старше суток |
| A10 | Mini App открывается в web MAX | не проверено | Web layout и Bridge fallback протестированы в Chromium | Пройти основной сценарий в web.max.ru |

Ручные результаты записываются только в [scripts/smoke-real.md](../scripts/smoke-real.md), после чего статусы переносятся сюда. Без фактического подтверждения платформы статус не повышается до `закрыто`.
