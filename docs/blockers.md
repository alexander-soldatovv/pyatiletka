# Внешние блокеры

Дата: 30.09.2026.

1. Для проверки A1-A10 нужны токен бота, доступ к настройкам бота и клиенты MAX на iOS, Android и в вебе.
2. Для production нужны публичный HTTPS-адрес и возможность задать URL мини-приложения в настройках выданного бота.
3. Docker CLI версии 29.3.1 и отдельный `docker-compose` установлены, но демон недоступен через `/var/run/docker.sock`; Compose plugin `docker compose` отсутствует. Поэтому образ, время холодной сборки, non-root внутри контейнера и container healthcheck не проверены. После запуска Docker Desktop выполнить `scripts/verify-docker.sh` на машине с Compose v2.
4. Для подтверждения продуктовой гипотезы нужны результаты опроса аудитории 50-65 лет.
5. Выпускающий Russian Trusted Sub CA из официального bundle действует до 06.03.2027. Перед production-развёртыванием нужно снова открыть `https://www.gosuslugi.ru/crt` и заменить bundle, если опубликована новая цепочка.
