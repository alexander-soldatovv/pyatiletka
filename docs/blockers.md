# Внешние блокеры

Дата: 29.09.2026.

1. Для проверки A1-A10 нужны токен бота, доступ к настройкам бота и клиенты MAX на iOS, Android и в вебе.
2. Для production нужны публичный HTTPS-адрес и возможность задать URL мини-приложения в настройках выданного бота.
3. Для проверки TLS из контейнера нужен официальный сертификат Минцифры и работающий Docker.
4. Для подтверждения продуктовой гипотезы нужны результаты опроса аудитории 50-65 лет.
