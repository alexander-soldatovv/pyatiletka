# Известные ограничения

Дата обновления: 30.09.2026.

- Реальный токен MAX не предоставлен, поэтому допущения A1-A10 пока не проверены в клиентах MAX.
- P6 preflight без токена подтвердил CA, payload `open_app`/`clipboard` и TLS до MAX. Это не заменяет авторизованный `GET /me` и ручную матрицу iOS, Android и web из `scripts/smoke-real.md`.
- Этапы P1-P5 реализуют автономное ядро, бот, очередь отправки, HTTP-mock MAX, внутренний API, мини-приложение, напоминания, наблюдаемость и Docker-конфигурацию.
- Поведение `open_app`, `clipboard` и редактирования старого callback-сообщения проверено на mock по контракту API, но не в реальных клиентах MAX.
- MAX Bridge загружается и его методы вызываются в обычном Chromium, но транспорт MAX там недоступен. `BackButton`, haptic, `openLink`, `shareContent` и запуск по `open_app` ждут ручной проверки в MAX на iOS, Android и вебе на P6.
- `shareMaxContent` добавлен как актуальный web/desktop путь перед link-fallback, но его реальный экран выбора адресата ещё не подтверждён.
- Скриншоты P3 проверены локально в Chromium на 360x640 и 390x844. Это не заменяет проверку встроенного WebView MAX.
- Напоминания проверены с виртуальными часами и mock MAX, но их реальная доставка после `bot_stopped` и при сетевых ограничениях платформы ждёт P6.
- Годовые уведомления отправляются только в настроенные календарные даты. Если сервис недоступен весь такой день, этот слот будет пропущен; остаются следующие даты в том же году.
- Планировщик рассчитан на один экземпляр сервиса с одной SQLite БД. Для нескольких реплик потребуется общая БД и распределённая блокировка.
- Healthcheck определяет готовность polling по состоянию клиента библиотеки, но не выполняет отдельный синтетический запрос к MAX на каждый вызов.
- Досрочные пенсии не рассчитываются. При признаке `early=yes` продукт обязан направлять пользователя в СФР.
- Региональный пакет Москвы содержит ссылку на официальную страницу, но возрастные условия программы ещё требуют отдельной проверки.
- Справка о статусе предпенсионера и срок её формирования пока основаны на вторичном источнике 2023 года.
- Bundle сертификатов Минцифры и TLS до `platform-api2.max.ru` проверены с хоста: API вернул ожидаемый HTTP 401 без токена. Проверка из контейнера, холодная сборка и healthcheck заблокированы отсутствующим Docker daemon.
