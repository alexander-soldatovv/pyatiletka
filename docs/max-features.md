# Расширенное использование MAX

Дата проверки документации: 30.09.2026.

Мини-приложение подключает официальный скрипт `https://st.max.ru/js/max-web-app.js`. Все вызовы Bridge защищены проверкой наличия метода и обработкой отклонённого Promise, потому что набор возможностей различается между мобильными, desktop- и web-клиентами.

| Возможность | Где используется | Как проверить |
|---|---|---|
| `open_app` | Кнопка запуска карты в сообщении бота. При отказе API бот повторяет сообщение с link-диплинком. | В чате нажать «Открыть карту», убедиться, что Web App открылся для того же пользователя. Проверка на реальном боте запланирована на P6. |
| `initData` | `public/app.js` передаёт исходную строку в `X-Max-Init-Data`; сервер проверяет HMAC, `auth_date` и берёт `user.id` только из проверенных данных. | API-тесты покрывают свежую, отсутствующую, чужую и устаревшую подписи. На P6 сопоставить ID с командой бота. |
| `BackButton` | Показывается в карточке шага, возвращает к списку, затем скрывается. Старый обработчик снимается через `offClick`. | Открыть карточку шага в MAX, нажать нативную кнопку назад, проверить возврат к списку без двойного вызова. |
| `HapticFeedback` | `notificationOccurred('success'|'error')` после отметки шага, сохранения профиля и копирования. | Проверить на iOS и Android. Официально метод не поддерживается в desktop- и web-клиентах. |
| `platform` и `shareContent` | На iOS и Android кнопка «Поделиться картой» вызывает системный экран шеринга с текстом. | Проверить системный share sheet на двух мобильных платформах. |
| `shareMaxContent`, `openMaxLink` и `:share` | На web/desktop сначала используется актуальный Bridge-метод внутреннего шеринга, затем link-fallback. | Нажать «Поделиться картой» в web/desktop MAX и проверить экран выбора адресата. |
| `openLink` | Официальные источники и каналы шага открываются по явному клику пользователя. | Открыть карточку, нажать источник, проверить внешний браузер и правильный URL. |
| Clipboard | В Web App список документов и текст работодателю копируются через Clipboard API, с запасным `document.execCommand('copy')`. В боте используется кнопка `clipboard`. | Вставить скопированный текст в поле сообщения. Проверить Web App и чат отдельно. |

Официальные источники: [MAX Bridge](https://dev.max.ru/docs/webapps/bridge), [подключение мини-приложения](https://dev.max.ru/docs/webapps/introduction), [валидация initData](https://dev.max.ru/docs/webapps/validation).

Реальный транспорт MAX в P3 не проверен. Матрица iOS, Android, desktop и web должна быть заполнена человеком на P6.

Для P6 диплинк `?startapp=smoke` включает диагностический блок в профиле. Он показывает только текущему пользователю ID из серверно проверенного `initData`, платформу и версию клиента. Это позволяет сравнить значение с `/id` без доверия к `initDataUnsafe` и не влияет на обычный запуск.
