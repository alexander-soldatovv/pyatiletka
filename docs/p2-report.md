# Отчёт P2

Дата: 29.09.2026.

## Проверено

- Бот работает на `@maxhub/max-bot-api` 0.3.1 и использует фактические сигнатуры установленной библиотеки.
- `bot_started`, все команды и мастер настройки обрабатываются через библиотечный polling-клиент.
- Состояние мастера хранится в SQLite и продолжается после перезапуска процесса.
- Callback редактирует исходное сообщение. Ошибка редактирования приводит к отправке нового сообщения.
- Реализованы ошибки даты, длинного ввода, вложения вместо текста, неизвестного и повторного payload, старой кнопки после reset и задачи без профиля.
- Проверены ветки занятости `other`, досрочной пенсии `yes` и `unsure`, отметка шага и возврат отметки.
- Очередь соблюдает предел два сообщения в секунду на диалог. 429 и 5xx повторяются с ограниченной экспоненциальной паузой.
- Отказ `open_app` приводит к кнопке с официальным диплинком `?startapp=plan`.
- HTTP-mock покрывает `/me`, `/updates`, `/messages`, `/answers`, `/subscriptions`, `/me/commands`; удалённый `/chats` явно отвечает 410.
- `BOT_TOKEN` берётся только из окружения. Без него запуск завершается понятной ошибкой без значения секрета.

## Не проверено

- Реальный токен и клиенты MAX не предоставлены. A1-A10 остаются открытыми до этапа P6.
- Не проверено фактическое поведение `open_app`, если URL мини-приложения не задан в настройках реального бота.
- Webhook проверен по сигнатурам библиотеки, но его e2e-проверка запланирована вместе с HTTP-сервером.
