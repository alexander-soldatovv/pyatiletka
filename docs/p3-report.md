# Отчёт P3

Дата: 29.09.2026.

## Реализовано

- Один `node:http` сервер раздаёт `public/`, внутренний API, `/healthz` и webhook MAX.
- Добавлены CSP для `st.max.ru`, `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy`, лимит тела, таймауты и единый JSON-формат ошибок без stack trace.
- API проверяет `X-Max-Init-Data`, HMAC и свежесть `auth_date`; `user.id` берётся только из подтверждённых данных. Демо-доступ выключен по умолчанию и требует одновременно `ALLOW_DEMO_AUTH=true`, `?demo=1` и специальный заголовок.
- Профиль, задачи и удаление используют ту же SQLite БД, что и бот. Тест проверяет видимость отметки в обе стороны.
- Web App содержит карту, три даты, список и карточку шага, профиль, состояния загрузки, ошибки, отсутствующего профиля и устаревшей сессии.
- Подключены `BackButton`, haptic, `openLink`, мобильный share и `:share` fallback, Clipboard API и запасное копирование.
- Реализованы светлая и тёмная темы, базовый шрифт 18 px, режим 21 px, контролы от 48 px, keyboard focus и reduced motion.

## Проверено локально

| Проверка | Результат |
|---|---|
| Подписанный, отсутствующий, чужой и устаревший initData | Автотесты проходят |
| Идемпотентная отметка и `DELETE /api/me` | Автотесты проходят |
| Общее состояние API и бота | Автотест проходит в обе стороны |
| Демо-авторизация по явному флагу | Автотест и ручной запуск проходят |
| Chromium 360x640, светлая тема | Карта проверена, снимок сохранён |
| Chromium 390x844, тёмная тема | Карточка шага и отметка проверены, снимок сохранён |
| Открытие без initData | Показано «Откройте из MAX» |
| Консоль Chromium | Ошибок приложения нет; Bridge ожидаемо сообщает, что транспорт MAX вне клиента недоступен |
