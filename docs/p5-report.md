## Docker-блокер

Docker CLI 29.3.1 доступен, но daemon не запущен и socket `/var/run/docker.sock` отсутствует. В установленном CLI также нет Compose plugin; доступен отдельный `docker-compose`, которым выполнена статическая проверка. Поэтому не заявляются:

- успешная сборка `node:22-slim`;
- фактическое время холодной сборки и соблюдение лимита 5 минут;
- non-root и healthcheck в запущенном контейнере;
- TLS именно из контейнера.

Для закрытия блокера на машине с Docker Compose v2 нужно запустить `scripts/verify-docker.sh`. Скрипт останавливается с понятной ошибкой, если daemon недоступен, и не требует токен для сборки/non-root/TLS проверки. Live healthcheck выполняется только при наличии локального `.env` с токеном.

## Сертификат

Официальная страница `https://www.gosuslugi.ru/crt` открыта 30.09.2026. Среда изначально не доверяла её цепочке, поэтому прямые публичные PEM были получены с домена раздачи `gu-st.ru` с bootstrap-исключением TLS и затем проверены по субъектам и SHA-256. После подключения bundle Node.js установил проверенный TLS к MAX. Выпускающий сертификат истекает 06.03.2027, поэтому перед production его нужно сверить повторно.
